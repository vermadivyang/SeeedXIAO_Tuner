# SeeedXIAO_Tuner
Code for a violin tuner built on the Seeed XIAO nRF52840 Sense Plus, featuring a dedicated PDM microphone. It samples audio at 16 kHz, applies a Hann window and FFT (Fourier Transform), then analyzes harmonic frequency peaks to determine the played note and tuning error in cents.
